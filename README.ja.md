# Novel Chart Builder（ノベルゲーム フローチャート作成ツール）

[English](./README.md) | [日本語](./README.ja.md)

**Bun**, **TypeScript**, **React 19**, **SQLite (`bun:sqlite`)** で構築された、ノベルゲーム・アドベンチャーゲームのシナリオ分岐設計向けフローチャート作成ソフトです。

---

## 主な機能

- **上から下へつなぐシンプルなチャート構築**
  - **四角（節 / Section）** と **ひし形（分岐 / Branch）** の下に表示される丸い「＋」ボタンから、次の図形（四角・ひし形）を直感的に追加して線でつなげていけます。
- **章分け（水平レーン）と高さリサイズ**
  - 大きな区分けとして、キャンバス全体が水平線で「章エリア（`CHAPTER 1`, `CHAPTER 2`...）」に分かれています。
  - 各章のタイトル編集、章の追加・削除、および**章の境界線を上下にドラッグして高さを自在にリサイズ**できます。
- **右側ドロワーによる詳細編集**
  - **四角（節）をクリックしたとき**:
    - 「節のタイトル」入力欄、その下に「本文・シナリオテキスト」を全文入力できるテキストエリアが表示されます。
    - 四角のドロワーでのみ **「ENDフラグ」** を設定でき、ONにするとその四角の下には「＋」ボタンが表示されなくなります。
    - ENDでない四角から直接複数ルートへ分岐させることも可能です。
  - **ひし形（分岐）をクリックしたとき**:
    - 「分岐のタイトル」入力欄と「テキストエリア」に加え、**「分岐先の個数」**を選択できます。
    - 選択した分岐先の個数分だけ、ひし形の下に丸い「＋」ボタンが表示されます。
- **未接続の分岐があるひし形の赤色ハイライト**
  - ひし形で設定した分岐先が1つでもまだ作られていない（未接続の）場合は、**ひし形の色が赤色**になり、作りかけの分岐を一目で判別できます。すべて接続されると通常色（青）に変わります。
- **分岐の線へのコメント記入**
  - 接続線（またはドロワー内の接続一覧）から、`「SAN値が80以下の場合」` のような条件コメントを線に直接書き込んで表示できます。
- **既存ノードへの合流（マージ）**
  - 「＋」ボタンのメニューから `🔗 既存の図形へ合流` を選ぶことで、分岐したルートを既存の別ノードへ線でつなげて合流させられます。
- **重なりを回避する自動ソート（自動整列）**
  - ヘッダーの `⇄ 自動ソート（整列）` ボタンで、親子関係と分岐順序に沿って上から下へ自動整列します。
  - `導入 → 2節 → 3節` と `導入 → 3節` のような階層をまたぐスキップ接続がある場合も、仮想通過レーン計算と迂回ベジェ曲線により、線が途中の図形の裏に隠れないよう配置されます。
- **複数選択モード ＆ グループ移動 ＆ まとめて削除**
  - キャンバスの空白部分をドラッグして複数の図形をまとめて範囲選択できます。
  - `Ctrl + クリック`（Macは `Cmd + クリック`）で、選択グループから1つずつ選択解除（または追加）できます。
  - 複数選択した状態で選択中の図形をドラッグすると、**互いの位置関係を保ったまままとめて移動**できます。
  - 上部バーの「🗑 まとめて削除」ボタンまたは `Delete` / `Backspace` キーで一括削除できます。
- **元に戻す / やり直す（Undo / Redo）**
  - まとめて削除・単体削除・図形の移動・自動ソートなどの操作履歴を保持しており、削除直後のトースト通知ボタン、ヘッダーの `↩ 元に戻す` ボタン、または `Ctrl + Z` でいつでも元の状態（接続線やコメントを含む）に復元できます。
- **拡大・縮小（ズーム）**
  - `Ctrl + マウスホイールスクロール` または画面右下の `－` / `100%` / `＋` ボタンで `30%` 〜 `200%` のズームが可能です。
- **SQLite & LocalStorage 自動保存 ＋ JSON入出力**
  - 編集内容はリアルタイムでローカルの SQLite（`data/flowchart.sqlite`）およびブラウザの `localStorage` に自動保存されます。JSONファイルとしてのエクスポート／インポートにも対応しています。

## 技術スタック

- **ランタイム & バンドラ**: [Bun](https://bun.sh/) (`Bun.serve` フルスタックサーバー)
- **データベース**: `bun:sqlite` (標準内蔵SQLite・WALモード)
- **フロントエンド**: React 19 + TypeScript 7

## セットアップ・起動方法

### 必要環境

- [Bun](https://bun.sh/) v1.2 以上

### 依存パッケージのインストール

```bash
bun install
```

### 開発サーバーの起動

```bash
bun run dev
```

ブラウザで `http://localhost:3000` を開くと利用できます。

### 型チェック・テストの実行

```bash
# TypeScript 型チェック
bun run typecheck

# テストの実行（SQLite永続化・自動ソート・一括削除・グループ移動）
bun test
```

## Cloudflare (Workers + D1) へのデプロイ手順

追加の外部ライブラリに依存しない Cloudflare Worker エントリポイント（[`src/worker.ts`](./src/worker.ts)）および D1 スキーマ（[`schema.sql`](./schema.sql)）を同梱しています。既存の他プロジェクトの Worker や D1 データベースとは別名で独立して動作するため、競合しません。

1. **Cloudflareへのログインと専用の D1 データベース作成（初回のみ）**:
   ```bash
   bun x wrangler login
   bun x wrangler d1 create novel-chart-builder-db
   ```
2. 出力された `database_id` を [`wrangler.jsonc`](./wrangler.jsonc) の `database_id` に貼り付けます。
3. **テーブルの初期化**（省略可：[`src/worker.ts`](./src/worker.ts) が初回アクセス時に自動作成もします）:
   ```bash
   bun x wrangler d1 execute novel-chart-builder-db --remote --file=./schema.sql
   ```
4. **Google 認証（アクセス制限）の設定**:
   - **方法A：Cloudflare Zero Trust (Access) を使う場合（推奨）**:
     1. Cloudflare ダッシュボードの **Zero Trust > Access > Applications** から **Self-hosted** アプリケーションを作成し、Worker のドメイン（`novel-chart-builder.<サブドメイン>.workers.dev`）を登録します。
     2. ログイン方法に **Google** を指定し、許可する自分の Google メールアドレスを Allow ポリシーに設定します。
     3. （任意・二重防御）[`wrangler.jsonc`](./wrangler.jsonc) の `vars.ALLOWED_EMAILS` にも自分のメールアドレス（例: `"your-email@gmail.com"`）を設定しておくと、Worker 側でも全 `/api/*` リクエストでメールアドレスを検証します。
   - **方法B：アプリ内蔵の Google ログインボタン (`GOOGLE_CLIENT_ID`) を使う場合**:
     1. [`wrangler.jsonc`](./wrangler.jsonc) の `vars` に `"GOOGLE_CLIENT_ID"` と `"ALLOWED_EMAILS"`（許可するGoogleメールアドレス）を設定します。
5. **ビルド＆デプロイ**:
   ```bash
   bun run cf:deploy
   ```

## ショートカット・操作一覧

| 操作内容 | ショートカット / マウス操作 |
| :--- | :--- |
| **単一選択（ドロワーを開く）** | 図形をクリック |
| **まとめて範囲選択** | キャンバスの空白部分をドラッグ |
| **個別選択の追加・解除** | `Ctrl + クリック`（Macは `Cmd + クリック`） |
| **選択グループのまとめて移動** | 複数選択中に選択された図形をドラッグ |
| **選択中の図形をまとめて削除** | `Delete` または `Backspace` キー |
| **元に戻す (Undo) / やり直す (Redo)** | `Ctrl + Z` / `Ctrl + Y`（または `Ctrl + Shift + Z`） |
| **拡大・縮小（ズーム）** | `Ctrl + マウスホイール`（または右下の `＋` / `－` ボタン） |
| **選択解除 / モードキャンセル** | `Escape` キー |
